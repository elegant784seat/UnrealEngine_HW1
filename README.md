# Unreal Engine — домашнее задание №1

Расширение Third Person Template: спринт, взаимодействие через делегат, состояние анимации Sprint и выносливость.

## Требования и запуск

- Unreal Engine **5.8** (проект разрабатывался в 5.8.3).
- Инструменты сборки C++ для вашей платформы; на macOS — Xcode с компонентом Metal Toolchain.

1. Клонируйте репозиторий.
2. Откройте `MechanicsHW.uproject` и согласитесь собрать модуль проекта, если редактор предложит это сделать. Проект также можно собрать из Rider.
3. Откройте уровень `Content/ThirdPerson/Lvl_ThirdPerson` и нажмите **Play**.
4. Щёлкните внутри игрового окна и используйте английскую раскладку клавиатуры.

## Управление

| Клавиша | Действие |
| --- | --- |
| WASD | Перемещение |
| Мышь | Поворот камеры |
| Пробел | Прыжок |
| Left Shift (удержание) | Спринт |
| E | Взаимодействие |
| Esc | Завершение проверки в редакторе |

## Реализация

- `AMechanicsHWCharacter` наследуется от `ACharacter`; `BP_ThirdPersonCharacter` использует этот C++ класс как родительский.
- Действия `IA_Sprint` и `IA_Use` добавлены в `IMC_Default`, обработчики подключены через Enhanced Input в `SetupPlayerInputComponent`.
- Спринт меняет `MaxWalkSpeed` с 500 до 650 см/с и выставляет `bIsSprinting`, доступную для чтения из Blueprint.
- Функция `Use()` вызывает `OnInteraction.Broadcast()`. В Blueprint при BeginPlay подключается обработчик делегата, который выводит сообщение через Print String.
- `ABP_Unarmed` читает состояние спринта. В машине `Locomotion` добавлено отдельное состояние `Sprint` с циклической анимацией `MF_Unarmed_Jog_Fwd` и переходами по булевой переменной.
- Выносливость начинается со 100 и расходуется со скоростью 20 единиц в секунду при активном спринте. Расход рассчитывается в C++ через `Tick` с учётом `DeltaTime`.
- При нуле спринт прекращается даже при удержании Shift; повторный запуск спринта блокируется. Значение выводится на экран.
- Восстановление выносливости не реализовано: для сброса до 100 нужно перезапустить Play.

## Проверка

Вручную проверены сборка и запуск, ускорение и его отключение, взаимодействие на E, анимация спринта, расход выносливости и прекращение спринта при нуле.
